# Atividade — Análise e Projeto de Sistemas

Este repositório contém a refatoração de 5 códigos em Python, solicitada na disciplina de **Análise e Projeto de Sistemas**.

## Objetivo

Aplicar boas práticas de desenvolvimento, deixando os códigos mais organizados, legíveis e fáceis de manter.

## Arquivos

- `codigo_1_produtos.py`
- `codigo_2_idade.py`
- `codigo_3_salario.py`
- `codigo_4_clientes.py`
- `codigo_5_alunos.py`

## Boas práticas aplicadas

- Uso de funções
- Redução de repetição
- Nomes de variáveis mais claros
- Melhor organização do código
- Separação entre cálculo e exibição
